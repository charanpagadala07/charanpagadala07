A computer vision application that recognizes Indian Sign Language gestures and converts recognized signs into speech to support accessible communication.

- Achieved 98.3% recognition accuracy in project evaluation.
- Processed webcam input through landmark extraction and feature normalization.
- Integrated FastAPI-based inference with gender-adaptive speech synthesis.
- Evaluated live inference performance at approximately 20–40 FPS.

**Tech Stack:** Python, CNN, MediaPipe, OpenCV, DeepFace, FastAPI, Computer Vision
